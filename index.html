About

Design-minded, detail-driven

I'm a developer and designer based in Kampala. I came to the web through a fascination with how things work, and stayed for the problem-solving.

Most of my work sits where design and engineering meet: laying out a page so the hierarchy is obvious, then building it so it loads quickly, works on a phone, and stays usable with a keyboard. I've built everything from static restaurant sites to a React application with authentication, an admin dashboard and a Supabase back end.

I'm currently looking for front-end work — full-time, contract or freelance.
